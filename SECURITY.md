## 🔍 Security Scope

`zairakai/laravel-activity` extends Spatie Activity Log for Eloquent relation activity:

- no raw SQL queries generated by this package
- no dynamic code execution (`eval`, `exec`, shell calls)
- no external network calls

This package persists activity data through your application database. You remain
responsible for output escaping, authorization, and data retention policies.
